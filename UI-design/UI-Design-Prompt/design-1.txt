# Build Brief — Personal Apps & Websites Showcase

Build a polished personal portfolio web app for showcasing my **mobile apps and websites**.

The goal is to make the site feel **handcrafted, creative, personal, and memorable** — NOT like a typical AI-generated SaaS landing page.

## Tech Stack

Use:

* React.js
* Vite
* TypeScript
* Tailwind CSS
* Lucide React for icons
* React Router for navigation
* No backend required
* Static project data stored locally in TypeScript/JSON

The application should be fully responsive across:

* Desktop
* Tablet
* Mobile

---

# 1. Overall Design Direction

The visual style should feel like a:

> **Developer's personal sketchbook / digital workspace / creative notebook**

Think:

* Hand-drawn elements
* Paper/card textures
* Sticky notes
* Doodles
* Sketch-style arrows
* Slightly imperfect borders
* Warm off-white backgrounds
* Black ink typography
* Small handwritten annotations
* Occasional pastel accent colors
* Subtle shadows
* Editorial composition
* Asymmetric layouts

Avoid the common:

* Generic SaaS dashboard
* Excessive gradients
* Glassmorphism everywhere
* Huge rounded rectangles
* Purple/blue AI landing page aesthetic
* Perfectly symmetrical layouts
* Excessive animations
* Corporate portfolio appearance

The website should look like a developer has **physically designed it in a notebook and then converted it into a website**.

# 10. APP DOWNLOAD FUNCTIONALITY

Each app object should contain:

```typescript
type AppProject = {
  id: string;
  name: string;
  description: string;
  category: string;
  version: string;
  downloads?: string;
  icon: string;
  apkUrl: string;
  githubUrl?: string;
};
```

Example:

```typescript
const apps: AppProject[] = [
  {
    id: "habit-track",
    name: "HabitTrack",
    description: "Build better habits, one day at a time.",
    category: "Productivity",
    version: "1.0.0",
    downloads: "10K+",
    icon: "/icons/habittrack.png",
    apkUrl: "https://github.com/USERNAME/REPO/releases/download/v1.0.0/app-release.apk",
    githubUrl: "https://github.com/USERNAME/REPO"
  }
];
```

The Download APK button should:

1. Open/download the APK directly.
2. Use the GitHub APK URL.
3. Prefer an `<a>` element with the `download` attribute where possible.
4. If the browser does not allow forced download for a cross-origin GitHub URL, gracefully navigate to the APK URL so Android/browser download begins normally.

Example:

```tsx
<a
  href={app.apkUrl}
  download
  target="_blank"
  rel="noopener noreferrer"
>
  ↓ Download APK
</a>
```

Make the download action visually obvious.

# 28. FINAL QUALITY BAR

Before finishing:

1. Run the application.
2. Verify every route.
3. Verify responsive behavior.
4. Verify dark mode.
5. Verify APK download buttons.
6. Verify external website links.
7. Verify no broken images.
8. Verify no horizontal scrolling on mobile.
9. Verify keyboard accessibility.
10. Verify TypeScript has no errors.
11. Verify there are no console errors.
12. Make sure the UI does NOT look like a generic AI-generated SaaS template.

The final result should feel like:

> **"A developer's physical sketchbook turned into an interactive website."**

It should be creative enough that someone remembers the website after visiting it once.
